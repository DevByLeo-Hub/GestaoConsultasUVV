# Sistema de Gestão de Consultas UVV (AOP02)

Projeto prático desenvolvido em ASP.NET Core MVC (C#) para a disciplina de Desenvolvimento Web Back-end. O sistema permite o cadastro de usuários, autenticação, e o CRUD completo (Agendar, Listar, Editar e Cancelar) de consultas médicas.

## ⚙️ Arquitetura e Tecnologias
* **Linguagem:** C# (.NET 8)
* **Framework:** ASP.NET Core MVC
* **Banco de Dados:** SQL Server Express
* **ORM:** Entity Framework Core (Code First)

## 🗄️ Configuração do Banco de Dados
Para testar e rodar este projeto localmente, certifique-se de ter o SQL Server configurado e execute as Migrations. Abra o terminal na pasta raiz do projeto e rode o comando abaixo para gerar o banco de dados automaticamente:

`dotnet ef database update` 
*(ou `Update-Database` caso utilize o Console do Gerenciador de Pacotes do Visual Studio).*
